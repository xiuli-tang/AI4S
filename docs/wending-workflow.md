# 问鼎储能 · 产品主线与候选报告

对外品牌为“问鼎储能”，产品名为“问鼎·材料引擎”。材料数据、智能筛选、规律解释、决策与验证围绕同一候选身份组织。

## 首次使用

1. **选场景**：默认“固态电解质”，加载含 Li、O 的真实 MP 数据，以带隙为主目标，联合查看热力学稳定性和原料价格。PCEC/SOFC、催化显示为后续场景；自有数据已可从专家模式导入。
2. **AI 筛选**：默认 GP + UCB、2000 条候选、预算50。小数据集自动缩小预算。漏斗分别显示数据底座、条件匹配、实际载入、已评价和报告数量；对照曲线按相同初始样本与评价数比较随机选材。
3. **候选报告**：Top 3 为已评价优选，逐个回答“它好不好、为什么好、值不值得做、结构稳不稳、怎么验证”。未评价的下一步候选在专家模式单列。

## 五项研究答案

| 问题 | 内容与操作 |
| --- | --- |
| 它好不好 | 原单位的已评价结果、采样前预测；进入真实结构查看 |
| 为什么好 | 解析公式、白话方向解释；展开方法与独立测试指标 |
| 值不值得做 | 性能、稳定性、质量分数加权原料价格；性能优先、均衡、成本优先 |
| 结构稳不稳 | 按材料身份关联的 MACE 构型能量、受力与收敛记录 |
| 做出来怎么确认 | 理论/上传 XRD、主相拟合、合成预审与综合研究解读 |

单目标已评价记录自动进入决策摘要，不额外计一次评价。缺失的价格、结构或实验记录显示待补充；不同材料的构型或谱图不会互相代用。公式和构型结果保留各自的独立验证指标。

## 专家模式

数据源、七种预测模型、四种获取策略、预算、批次、自定义结构及 DFT–实验配对校准归入专家设置。规律分析与多目标计算从报告对应问题进入。策略示意动画、Mock 与主题切换不再占用产品入口；工程测试夹具保留。

## 一种报告，两类来源

- 研究工作台与自己的研究存档共用完整报告组件。
- 示例入口使用同一组件，保留“预置示例”标记；其中 MP 档案、独立 SrTiO₃ MACE 计算、合成演示谱及预置解读分别记录。
- 网页报告为独立 HTML，包含候选、公式、曲线、决策表、晶胞示意、谱图及来源，可离线打开、打印为 PDF。
- JSON 用于完整保存与继续研究。IndexedDB 只存在当前浏览器，换设备前应导出。

## 科研验证

真实多种子脚本接收 /api/hub/materials 返回的完整 HubResponse JSON：

~~~bash
npm run benchmark:learning -- --input materials.json --seeds 20 --budget 50 --output result.json
npm run benchmark:learning -- --input materials-with-llzo.json --seeds 20 --budget 50 --rediscover-formula Li7La3Zr2O12 --output llzo.json
~~~

第二条命令将目标相同组成的所有记录排除出初始五条标签，记录首次找到目标的评价次数。目标不存在会报错，不会用合成标签补齐。当前回归及两张统计图见[验收记录](validation/wending-workflow-20261112.md)。

## 对外介绍与后续落地

三十秒介绍：储能材料研发需要在性能、稳定性、成本与验证条件之间反复取舍。问鼎储能把材料数据、智能筛选、结构计算与实验验证组织成一条流程，给每个优选候选一份可追溯的研究报告。先从固态电解质初筛切入，逐步接入离子迁移、界面性质及合作实验室的数据反馈。

合作试点应交付一个真实研究问题、一份候选报告和可追溯的反馈记录。商业验证从定制筛选项目开始，记录需求、使用反馈、付费意愿与重复使用情况，再评估订阅服务。合作意向、收入和真实合成结果需在完成后登记。

后续实验交付：推荐材料的合成与 XRD；电解质用途还需离子电导率/迁移和界面评价。PCEC/SOFC 场景建立条件一致的电极与氧空位数据；催化场景建立反应条件一致的活性数据。
