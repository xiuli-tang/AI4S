# AI4S 研究体验升级验收

验证于 2026-11-06（北京时间）完成，覆盖生产环境和浏览器研究流程。

## 交付内容

- 默认载入 2000 个候选，上限 5000；默认预算 50，界面按候选数限制预算并保留未观测材料。旧存档保留已有观测，重置后应用新预算范围。
- 使用相同初始记录、固定种子、无放回等概率随机采样作独立对照；横轴按实际评价数对齐。节省次数是达到当前结果的事后比较，允许负值，随机未达到时不编造次数。对照记录随研究存档保存，恢复时核验源标签与采样顺序。
- 多目标默认使用当前数据，完整非支配前沿保留；新增按研究偏好排序的前五项。缺失价格/目标的记录不会填造数据。
- 研究首页明确标记已有标签回放，并突出来源、版本、许可证和快照 SHA256。模拟谱与上传谱保持各自标记。
- 首次流程为选数据、开始学习、查看结果；高级研究工具和路演收进次级入口。缺少服务配置时提供面向用户的提示。
- 补齐中英文、页面标题和 html lang，以及 3D、XRD、研究存档等提示。用户自命名存档与原始资料保持原文。
- 告知保存仅在当前浏览器，并提醒导出 JSON；第 0 轮顾问提供三个示例问题，禁用无数据的排名复盘。
- 提高文字字号和对比度，调整手机指标布局及表格滚动；新增 favicon。主研究曲线改为按可见容器布局，切换路演未出现 Recharts 尺寸警告。
- 生产启用 gzip；hash 静态资源缓存一年并标记 immutable，HTML 使用 no-cache；高级模块按需加载。发布保留旧 hash 资源以支持已打开的页面。
